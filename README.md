# Crypto-AML-Heuristics-Public
Crypto-AML-Heuristics-Public
Notice: This repository serves as the public contact point and conceptual abstract for my ongoing research into Anti-Money Laundering (AML) frameworks for decentralized networks.

Due to strict Non-Disclosure Agreements (NDAs), enterprise security policies, and the sensitive nature of financial forensics (including transaction layering models and dusting attack isolation), the actual source code, heuristics data pipelines, and threat models are maintained in private, air-gapped repositories.

This public hub is used for coordinating conceptual architectural feedback with open-source fintech maintainers to ensure enterprise-grade security adoption.
